# OpenXWA for macOS

Move `OpenXWA.app` to Applications or another writable location and open it. On
first launch, select the directory containing the original X-Wing Alliance
game data. The selected directory is remembered in the per-user
configuration.

Original game data is not included. Application resources, Metal shaders, and
runtime libraries are contained inside the application and must not be moved
out of it.

To import a modded X-Wing Alliance installation, such as XWAU or TFTC, into an
OpenXWA mod, open OpenXWA Options from the datapad and choose the Mods tab.

Third-party license notices are in the `licenses` directory beside this file.
